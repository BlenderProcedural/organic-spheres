# Organic Spheres: showcase

This is the showcase site and embeddable material browser for **Organic Spheres**, a set of 16 fully procedural organic materials for Blender (4.5+, Cycles and EEVEE).

- Full showcase: `index.html`
- Embeddable browser: `embed.html`

This repository contains only preview renders and documentation. The materials themselves, as `.blend` files, are sold on Superhive and are not included here.

## Embedding

```html
<iframe src="https://blenderprocedural.github.io/organic-spheres/embed.html"
        width="100%" height="640" style="border:0;border-radius:12px"
        loading="lazy" title="Organic Spheres material browser"></iframe>
```

Add `?m=rose-thorn`, or any material id from `assets/materials.js`, to open the browser on a specific material.
